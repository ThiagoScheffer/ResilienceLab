# AWS visual references

FailureForge is an independent, browser-only resilience simulator. It is not affiliated with, sponsored by, or endorsed by Amazon Web Services.

The application uses AWS service names and the selected SVGs in `public/aws-icons/` as display presets for architecture education. They were sourced from the official AWS Architecture Icons toolkit and should be refreshed from the current toolkit before a material release:

- https://aws.amazon.com/architecture/icons/

No live AWS account, workload data, pricing data, or AWS API connection is used by this project.
